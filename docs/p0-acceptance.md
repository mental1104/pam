# 本地账单导入状态

已实现CMB/Alipay/WeChat Parser、Apple Vision分块OCR、原图关联/诊断、iOS多图/人工复核，以及后端预检/确认/持久待核/证据更正。正常链路不依赖LLM。

使用归一化横坐标、文本高度/相对间距/语义锚点，不写死设备像素或行高。支持日期上下文、已知拍摄日期下的相对日期、可用账户/余额验证；缺字段、歧义、低置信度、首尾不完整及未知版式均需人工复核。

Parser仍为实验实现，不保证发现全部漏行或兼容所有实际版式。公开自动化只用合成文本/坐标及Vision图片；真实语料、CSV对照、文件名/统计和报告不公开。RealStatementRegressionTests可在Apple环境读取部署者显式提供的私人语料，缺少时跳过；历史CSV不能自动升级为已逐笔人工确认的真值。

模拟器编译与界面操作、签名安装、真机分别验收。方法见[acceptance.md](acceptance.md)，各部署运行状态由私有运维资料维护。
