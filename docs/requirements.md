# 功能契约

Go模块化单体、PostgreSQL、REST/MCP共享应用服务、同源网页及原生SwiftUI。金额用十进制字符串/NUMERIC，来源、币种、日期精度与证据可追踪。

优先本地Apple Vision和招商/支付宝/微信确定性Parser，保留原文/坐标/置信度、图片尺寸/SHA、版本/诊断。版式适应图高和设备宽度变化；未知版式、歧义、缺字段、低置信度和残缺交易不静默入库。

导入需要幂等、逐行回执、稳定外部/文件行身份及原始数据；跨批次/来源相似只产生待核。预检不写交易，确认时再查重；待核跨会话保存，更正保留前后快照/理由/证据。记录范围不是完整账单覆盖，支付证据不自动证明商品。

iOS本地选图/OCR/证据/人工编辑确认，网页复用后端。MCP受限SELECT由AST与低权限角色共同限制；导入和待核写操作通过业务服务。每次SQL尝试保存原文/参数和终态，另存模式聚合；一致快照审计图表支持下钻/原因/耗时/筛选/分页，自刷新不新增记录。

只公开代码、通用配置和合成夹具，私人数据/配置/运行统计在仓库外。真实/合成测试、模拟器编译与真机验收分别报告。不实施银行抓取、目录监控、LLM自动OCR/分类、预算、净消费模型、投资、估值、复式记账或身份平台迁移。
