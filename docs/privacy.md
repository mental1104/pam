# 代码与私有数据

公开业务代码、迁移、通用配置、测试及明确标记的合成夹具。真实账单/截图/OCR/语料、来源覆盖统计、审计正文、备份、验收回执、个人域名/邮箱/路径和部署历史在仓库外维护。

配置样例用占位符，CI密码/令牌仅属于隔离合成环境，不能复用到生产。公开仓库路径与iOS Bundle/Keychain标识是应用命名空间，不是认证材料。

公开历史从检查后的源码快照重建，旧私人开发/部署历史独立私有归档，不通过公开分支、标签、PR或CI链接发布。提交作者使用GitHub noreply身份。

.gitignore与内容检查仅减少误提交，不替代逐项审核。提交前检查diff与历史，不向公开讨论/CI粘贴真实字段、统计或截图。审计留存数据库原文不意味着可以同步到源码仓库。
